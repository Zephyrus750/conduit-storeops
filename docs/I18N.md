# Languages

Conduit's interface comes in ShelfSearcher's seven languages: English,
German (`de`), French (`fr`), Filipino (`fil`), Vietnamese (`vi`), Spanish
(`es`) and Italian (`it`). Each device picks its own in Settings › Display
or on the sign-in card; the choice is saved with the device's preferences
and the app reloads in that language.

## How it works

- `js/i18n.js` loads the device's dictionary before anything renders and
  exports `tx(text, vars)` and `txn(n, one, many, vars)`.
- The key is the English text itself. With no translation the English shows.
- Each language's dictionary is `js/i18n/<code>.js`, merging one file per
  area from `js/i18n/<code>/<area>.js` (core, shell, guide, map, floor,
  floor2, stock1, stock2, dock1, dock2, admin). `test/unit/i18n.test.js`
  lists which client files belong to which area.
- `npm test` fails when a `tx()` key lacks any of the six translations, when
  a translation's `{placeholders}` or markup differ from the English, or when
  a dictionary keeps a key nothing uses. `I18N_AREA=floor npm run test:unit`
  checks one area.
- Dates use the browser's `Intl` in the chosen language (`js/ui.js`).

## Writing interface text

```js
import { tx, txn } from '../i18n.js';

tx('Plan route')                                   // a label
tx('{n} stops on this level', { n })               // a value: a {placeholder}
txn(n, '{n} shelf', '{n} shelves')                 // singular and plural
tx('Press <b>Plan route</b> to order the stops.')  // simple inline markup stays in the key
tx('Moved {code} to {bay}', { code: esc(code), bay: esc(bay) })   // data is escaped by the caller
```

- Wrap every word a person reads: text, buttons, headings, placeholders,
  `title` and `aria-label`, toasts, `confirm()` text, empty states, errors
  shown on screen, printed sheets, `document.title`.
- One key per sentence or label. Don't split a sentence into pieces around a
  value: put the value in a `{placeholder}`.
- The key is a plain string literal: never a template literal, never built
  from pieces. Simple tags (`<b>`, `<i>`, `<small>`, `<br>`, `<code>`,
  `<span class="…">`) may sit inside a key; every translation keeps them.
- The first argument of `txn` is a plain value (`n`, `list.length`), never an
  expression with commas.
- A label held in a variable (a tool's name from `shared/tools.js`, a day name
  from `shared/trends.js`) is translated where it is shown, `tx(name)`, and
  each English value is listed in `test/unit/i18n-keys/<area>.json` so the
  test knows to require it. `shared/` itself stays English: it runs on the
  worker too.
- Module-level arrays of labels may call `tx()` directly: the dictionary has
  loaded before any module that imports `tx` runs.
- When one English word means two things ("Open" the button and "Open" an
  issue's status; "Floor" the area and a building's floor), the key names
  which with a context before `::`: `tx('issue status::Open')`. English shows
  the text after `::`; each language translates the two keys apart. Every
  language file merges into one dictionary, so a plain key means the same
  thing on every screen.
- `tx` and `txn` are the names because `t` is a common local variable here.

## What stays in English

Data, never translated: shelf, run, bay and product codes; product, store,
department and micro-department names; D-numbers; manifest, consolidation,
cage and truck numbers; anything a person typed (team messages, notes,
issue titles). The codes printed on the company's reports and labels stay
as printed: SOH, APN, PDT, SIM, PULL, ADJUST, GHOST, RECOUNT, DEEP, RECENT,
FROZEN, Chep, Loscam. The brand name Conduit. Console logs, worker error
codes, event types and storage keys. The owner's map editor (`editor/`).

## Translations

Short, plain words a store team uses; the imperative for buttons. A
translation may not contain a straight double quote `"` (it would end an
HTML attribute): use the language's own quotes (« » „ “ ‘ ’). Keep every
`{placeholder}` and tag exactly. Filipino uses everyday Tagalog with the
English retail words Filipino store teams already use (shelf, stockroom,
pallet, scan, keycode). Keep the same word for the same thing everywhere:
